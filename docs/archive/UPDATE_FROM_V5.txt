현재 쓰는 DaySpark v5 폴더에 덮어쓰는 용도:

1. 실행 중인 DaySpark 서버를 모두 종료하세요.
2. PATCH ZIP을 기존 v5 폴더에서 '여기에 압축 풀기'로 풀고 덮어쓰기 허용.
   (src / scripts / README.md 등 경로가 기존 폴더와 겹쳐야 합니다.)
3. 기존 .tools, uploads, DB 파일은 삭제하지 마세요.
4. 00_START_DAYSPARK_CHROME.bat 을 더블클릭하세요.
   추가 서버 창 없이 백그라운드로 실행하고, 준비되면 Chrome이 열립니다.
5. 종료 시 03_STOP_DAYSPARK.bat. 오류 발생 시 02_OPEN_ERROR_LOG.bat.

이미 v5에서 다운로드한 .tools/apache-maven-3.9.9는 재사용됩니다.
앞으로 다른 새 ZIP에서 다시 Maven 설치를 요구하지 않도록
%LOCALAPPDATA%/DaySpark/tools 폴더에 재사용 복사합니다.

주의: 실제 Windows Spring Boot 전체 기동과 mvn test는 제작 환경에서
실행할 수 없었습니다. 컴파일 오류 수정 파일은 별도 javac 스텁 테스트 통과.
