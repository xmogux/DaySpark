# DaySpark: 크롬에서 원클릭 실행

1. 이 ZIP 파일의 **압축을 완전히 풀고**, `dayspark` 폴더로 들어갑니다.
2. **`01_OPEN_DAYSPARK_CHROME.bat`을 더블클릭**하면 서버를 자동으로 켜고, 준비되는 대로 크롬에서 실제 웹앱을 엽니다. 주소를 직접 입력할 필요가 없습니다.
3. **`02_OPEN_DEMO_CHROME.bat`을 더블클릭**하면 서버나 Java 없이 크롬에서 데모 화면이 즉시 열립니다. 이 데모는 브라우저 저장소를 사용하며, **실제 Spring Boot/H2 DB가 아닙니다**.

## 알아둘 점

- 실제 웹앱은 로컬 서버로 실행합니다. **첫 실행에는 인터넷 연결이 필요**할 수 있습니다(Maven/Java 의존성 다운로드). 준비가 끝난 뒤 크롬이 자동으로 열립니다.
- 백엔드 서버 콘솔은 최소화되어 작업 표시줄에 남아 있습니다. **해당 콘솔을 닫으면 웹앱 서버도 종료**됩니다.
- 이미 DaySpark가 실행 중이면 추가 서버를 만들지 않고 크롬만 엽니다.
- `8080` 포트를 다른 프로그램이 쓰고 있으면 메시지를 표시합니다. 다른 사이트를 DaySpark로 잘못 열지는 않습니다.
- 크롬을 찾을 수 없는 경우 Windows 기본 브라우저로 열립니다.
- 기능: 도전 CRUD, 반복 일정, 오늘 대시보드, 완료·사진·메모, 달력, streak, 통계.
- 기존 보고서 양식은 `reports/`에 모두 들어 있습니다.
- **압축파일 안에서 BAT만 열지 말고 압축 해제 후 실행**하세요.
- 이 환경에서는 Windows에서 Java 서버를 끝까지 기동해 보는 실기 테스트는 할 수 없었습니다. 실제 실행 문제가 나오면 최소화된 서버 창의 마지막 오류 메시지를 확인하세요.
