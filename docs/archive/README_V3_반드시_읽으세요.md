# DaySpark v3 — 목표 수치 + 일정 예외 + 포모도로

**실제 프로그램은 Java Spring Boot 기반 웹앱**입니다. `demo.html`은 별도의 서버 없는 체험판으로, DB 대신 해당 Chrome의 localStorage에 저장하므로 **두 버전의 기록은 공유되지 않습니다**.

## Windows에서 실행

1. ZIP을 완전히 압축 해제한 후 `dayspark` 폴더로 이동합니다.
2. 기존 v2 데이터베이스(`dayspark_v2.mv.db`)와 `uploads/`를 사용 중이었다면 업데이트 전 별도 위치에 백업합니다. 새 ZIP을 기존 폴더에 덮어쓰기보다 새 폴더를 이용하세요.
3. `01_OPEN_DAYSPARK_CHROME.bat`을 더블클릭합니다. 서버가 준비되면 Chrome에서 `http://localhost:8080`이 열립니다. 설치된 JDK 17+ 필요(Windows JDK 25 실행 스크립트 대응). 초기 Maven/라이브러리 설치에는 인터넷 접속이 필요할 수 있습니다.
4. Spring Boot 실행 오류는 `03_SHOW_STARTUP_ERROR.bat`, `04_OPEN_STARTUP_LOG.bat`으로 확인할 수 있습니다.
5. **실행 체험만 할 때:** `02_OPEN_DEMO_CHROME.bat` → Chrome에서 서버 없이 열기. 데모는 서버와 별개이며 localStorage가 데이터 저장소입니다.

## 새 기능 사용 순서

- **내 도전 관리 → 상세·통계**에서 목표 수치(분·페이지·회·개·잔)와 주간 완료 목표 설정. 같은 화면에서 진행량 직접 기록, 날짜 건너뛰기 또는 특정 날짜 추가.
- **집중 타이머**에서 연결할 도전, 집중 시간 1~120분, 휴식 시간 0~30분, 반복 횟수 1~10회 설정 후 시작. 원형 진행 표시, 일시정지/재개/중단 제공.
- **실제로 끝난 집중 회차만** 총 분·회차에 누적. 분 단위 목표에 연결했으면 진행량도 자동 증가. 휴식이나 중단한 시간은 추가되지 않음.
- **달력**의 날짜를 눌러 당일 완료와 집중 기록 확인; **통계**에서 오늘/이번 주/이번 달 총 집중 분·회차 확인.

## 사용 규칙 / 알려진 제한

- 완료 체크(메모/사진)와 목표 진행량 및 집중 시간은 **서로 다른 기록**입니다. 목표치를 충족해도 완료 체크가 자동으로 생성되지 않습니다.
- 주간 목표에서의 ‘회’는 포모도로 세션 횟수가 아니라 그 도전의 **완료 체크 날짜 수**입니다.
- 전체 Streak는 완료를 기록한 연속 달력일 기준입니다(쉬는 날을 자동 성공으로 처리하지 않음). 목표 상세의 연속 기록은 반복 예정일 기준입니다.
- 현재 단일 사용자 로컬 앱입니다. 반복 설정을 수정하면 과거 예정 분모가 새 규칙으로 재계산될 수 있습니다.
- 앱 시작 시 기존 DB 필드 추가는 Hibernate 자동 업데이트에 맡기므로 **업데이트 전 백업**하세요.
- 검증: 소스 수준 컴파일·도메인 단위 검사는 별도로 실시했지만 이 작업 환경에서 Maven 의존성 다운로드가 불가능해 전체 Spring Boot 기동까지 재현하지 못했습니다. `mvn test`를 본인 Windows에서 실행해 최종 통합 검증하세요.
