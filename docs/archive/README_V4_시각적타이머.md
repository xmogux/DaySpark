# DaySpark v4 — 눈에 보이는 포모도로 타이머

## 이번 업데이트

- **바깥 원(라임색)**: 선택한 전체 집중 시간(예: 25분) 중 경과한 비율에 맞춰 0%부터 100%까지 채워집니다.
- **안쪽 원(살구색)**: 매초 채워지는 60초 게이지입니다. 60초마다 0에서 다시 시작하며, 15초 미리보기에서는 15초에 한 바퀴 채워집니다. 오래 기다리지 않아도 눈으로 변화가 보이게 만들었습니다.
- **남은 시간 큰 숫자**: `25:00` → `24:59`처럼 줄어듭니다.
- **경과 시간 / 전체 시간, 실시간 %**, 전체 시간·1분 진행 막대가 함께 바뀝니다.
- **15초 움직임 테스트**: 실제로 집중 기록을 저장하지 않고 시각적 효과만 빠르게 확인합니다. 테스트도 일시정지·재개·중단 가능.
- 기존 완료 회차·집중 누적 분의 DB 연동은 변경하지 않았습니다. 테스트·중단 회차는 통계에 합산되지 않습니다.

## v3 사용자가 반복 다운로드하지 않고 수정하기

1. 실행 중인 DaySpark 서버 CMD 창을 **종료**합니다.
2. 기존 v3의 `dayspark` 폴더를 백업해 둡니다.
3. `DaySpark_v4_Visual_Timer_Patch.zip`을 열어 **v3 프로젝트의 `dayspark` 폴더 안에 압축 해제**합니다. `src`, `demo.html`, `preview.html`이 기존 파일을 덮어쓰도록 허용합니다.
4. 기존 `01_OPEN_DAYSPARK_CHROME.bat`을 실행합니다. 기존 `.tools`와 Maven 라이브러리는 그대로 유지합니다.
5. `집중 타이머` 화면 → `⚡ 15초 움직임 테스트` 클릭 → 게이지를 확인합니다.

위 패치는 **v3만** 대상으로 제작했습니다. 이전 v2에는 v3 타이머 파일 및 관련 API가 없으므로 적용하지 마세요.

## 전체 ZIP으로 새로 설치한다면

`dayspark/01_OPEN_DAYSPARK_CHROME.bat` 또는 `dayspark/02_OPEN_DEMO_CHROME.bat`을 사용하세요. 전체 ZIP을 새 폴더에 풀면 필요한 Maven을 해당 폴더에서 새로 다운로드할 수 있습니다. 기존 사용자에게는 패치 ZIP이 더 간단합니다.

## 작동 검증 범위

- Chrome 자동화로 로컬 HTML 데모의 게이지 진행, 일시정지/재개, 테스트 회차 비저장 및 일반 1분 회차 누적을 확인했습니다.
- 실제 Spring 템플릿 및 **동일한 focus.js**를 Chrome에서 모의 서버 응답과 연결하여 화면·상태·통계 표시를 테스트했습니다.
- 실제 Windows에서 새 ZIP을 실행해 Spring Boot를 기동하는 통합 검증은 여기서 수행하지 못했습니다. 서버 기동에 실패하면 `.tools/server_startup.log` 마지막 부분을 확인하세요.
