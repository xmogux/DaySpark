# DaySpark 변경 이력

DaySpark의 기능 추가와 주요 오류 수정 내역을 버전별로 기록한다. 실행 방법과 테스트 결과는 `README.md` 및 `docs/testing.md`를 참고한다.

## v5 — 핵심 기록·일정 규칙 보완

- 집중 세션의 정상 완료 날짜 계산을 수정했다.
- `GET /api/focus/current` 요청에서 데이터 변경 처리를 제거했다.
- 도전 분류, 반복 방식, 일정 예외 및 집중 상태의 입력 검증을 열거형 기반으로 정리했다.
- 도전의 쉬기 시작일을 기록하는 `pausedFrom` 필드를 추가했다.
- 연속 달성일(Streak)이 계획된 날짜를 기준으로 계산되도록 변경했다.
- 공통 오류 처리 및 오류 안내 화면을 추가했다.

## v5.1 — Java 17 호환성과 실행 안정성

- `CompletionService`의 람다 변수 참조로 인한 Java 17 컴파일 오류를 수정했다.
- 연속 달성일 계산 중 반복되던 과거 일정 조회를 줄였다.
- Windows 실행 과정의 서버 시작 오류 안내 및 로그 저장 방식을 개선했다.

## v5.4 — 월간 달력 개선

- 월간 달력을 7열 날짜 카드 형태로 개편하고 완료·일부 완료·예정·미완료·계획 없음 상태를 구분했다.
- 월간 완료 횟수, 달성률, 실제 집중 시간 및 완료 회차의 요약 지표를 추가했다.
- 날짜별 상세 기록으로 이동하는 기존 동작을 유지하면서 화면을 정리했다.

## v5.5 — 학습 복습 계획 추가

- 공부(`STUDY`) 도전에 복습 기준일과 사용자 지정 간격을 설정하는 기능을 추가했다.
- 오늘 화면, 도전 상세, 월간 달력 및 날짜 상세에서 복습 예정일과 완료 여부를 확인하도록 연결했다.
- 복습 완료 정보를 일반 도전 완료 기록과 구분해 저장하도록 했다.

## v5.6 — 업무 규칙과 데이터 처리 개선

- 반복 요일이 변경되더라도 완료 기록이 남아 있는 날짜는 계획일로 집계하도록 수정했다.
- 완료된 날짜의 일정 예외 초기화·쉬기를 제한해 완료 기록과 예정일 계산의 불일치를 방지했다.
- 지난 복습을 완료할 때까지 오늘 화면에 표시하도록 수정했다.
- 도전 생성 화면의 분류 목록을 실제 입력 검증 규칙과 일치시켰다.
- HTTP 404·405 오류 처리와 집중 완료 요청 실패 시 재시도 동작을 수정했다.
- 수동 완료 취소와 첨부 사진 정리 기능을 연결했다.
- 정상 완료된 집중 시간을 수치 진행량에 반영하고, 계획된 날짜에 목표를 처음 달성하면 자동 완료하도록 연결했다.
- 도전 입력을 `DareRequest`로 통합하고, 복습 간격 검증과 연속 달성일 계산을 각각 `ReviewIntervals`, `StreakCalculator`로 분리했다.
- 화면별 통계 계산을 `StatsService`에서 처리하도록 정리했다.
- Java 17, Maven Wrapper 및 GitHub Actions 기반 자동 테스트 환경을 구성했다.

## v5.7.0 — 집중 시간 기록 및 데이터 일관성 강화

- 집중 세션에 `STOPPED` 상태를 추가해 계획 시간 전에 종료하더라도 실제 집중한 시간을 기록하도록 변경했다. 중간 종료는 완료 회차나 목표 진행량에 반영하지 않는다.
- 집중 도중 다른 도전을 선택하면 기존 세션을 종료·기록하고 새로운 세션을 시작할 수 있도록 했다.
- 계획 시간이 이미 경과한 세션은 종료 요청을 받으면 정상 완료 상태로 처리한다.
- 도전 재개 시 이전 휴식일을 `SKIP` 일정 예외로 보존해 과거 계획 계산이 바뀌지 않도록 수정했다.
- 이미지 파일의 확장자와 기본 파일 형식을 검사하고, DB 트랜잭션의 성공 여부에 따라 신규·기존 첨부 파일을 정리하도록 했다.
- 집중 시작 및 도전 전환에서 DB 잠금을 사용해 동시 요청으로 활성 세션이 중복 생성되는 상황을 방지하도록 보완했다.
- 서버 날짜·시간 계산 기준을 `Asia/Seoul`로 통일했다.
