# DaySpark v5.5 — 공부 복습 플랜

## 추가 기능

- `STUDY` 카테고리 도전에 **복습 플랜**을 선택적으로 설정할 수 있습니다.
- 사용자가 직접 **복습 기준일**과 **복습 간격(일)** 을 입력합니다.
  - 예: `1, 3, 7, 14`
  - 입력값은 자동으로 정렬되고 중복이 제거됩니다.
  - 최대 12개, 각 간격은 1~3650일 범위입니다.
- 복습 일정은 일반 도전 일정/달성률과 분리되어 관리됩니다.

## 화면 표시

1. **오늘 화면**: 오늘 예정된 복습을 별도 영역에 표시하고 바로 완료할 수 있습니다.
2. **도전 상세**: 전체 복습 일정을 타임라인으로 보여주고 완료/미완료/오늘/예정 상태를 표시합니다.
3. **월간 달력**: 복습 예정일에 `↻ 복습 완료수/전체수`를 표시합니다.
4. **날짜 상세**: 해당 날짜의 복습 항목을 확인하고 완료 처리할 수 있습니다.
5. **도전 목록**: 복습 플랜을 사용하는 공부 도전에 복습 횟수 배지를 표시합니다.

## 데이터 모델

- `dares.review_enabled`: 복습 플랜 사용 여부
- `dares.review_base_date`: 복습 기준일
- `dares.review_intervals`: 정규화된 복습 간격 문자열
- `review_records`: 각 복습 간격별 완료 기록

복습 예정일 자체는 `review_base_date + offset_days`로 계산합니다. 따라서 예정일을 별도 테이블에 중복 저장하지 않습니다.

## 동작 규칙

- 복습 플랜은 `STUDY` 카테고리에서만 활성화됩니다.
- 카테고리를 다른 값으로 바꾸거나 복습 플랜을 끄면 기존 복습 완료 기록은 정리됩니다.
- 복습 기준일 또는 간격을 수정하면 기존 완료 체크는 초기화되어 새 플랜과 섞이지 않습니다.
- 도전을 일시정지한 이후 날짜의 복습은 오늘/달력 목록에서 숨겨집니다.
