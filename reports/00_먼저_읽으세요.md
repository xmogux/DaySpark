# 보고서·발표 자료

이 폴더에는 **제출용 양식**만 있습니다. 내용의 근거는 `docs/`에 있습니다.

| 파일 | 용도 | 채울 내용의 출처 |
|---|---|---|
| `01_DaySpark_요구사항_중간보고서_양식.docx` | 중간보고서 | `docs/requirements.md`, `docs/domain-rules.md` |
| `02_DaySpark_설계_최종보고서_양식.docx` | 설계·최종보고서 | `docs/architecture.md`(다이어그램), `docs/testing.md`(테스트 결과), `docs/process.md`(Git/CI), `docs/limitations.md` |
| `presentation_templates/…pptx` | 발표 양식 | 위와 같음 + 실행 화면 캡처 |
| `03_참고양식과_출처.md` | 양식을 참고한 외부 자료와 출처 표기 | — |
| `04_프로토타이핑_개선기록_양식.md` | 반복 개선 기록 양식 | 실제로 한 사용자 확인만 기록 |
| `07_새_발표양식_참고근거.md` | 발표 구성의 참고 근거 | — |

## 작성 규칙

1. 교수님이 준 공식 양식·분량 제한이 있으면 그것이 우선입니다.
2. 다이어그램은 `docs/architecture.md`의 Mermaid 코드를 [mermaid.live](https://mermaid.live)에서 PNG로 내보내 붙입니다.
3. 테스트 결과는 `./mvnw verify`를 **직접 실행한 결과만** 적습니다(`docs/testing.md` 4.1).
4. 하지 않은 설문·인터뷰·사용성 테스트는 한 것처럼 쓰지 않습니다.
