# v4 시각적 타이머 변경 기록 (중간/기말 보고서 참고)

## 사용자 요구사항

"집중 시간이 지나는 모습이 눈에 보이게 채워지거나 줄어들어야 한다."

## 개선 사유

v3는 25분 원형 트랙의 남은 비율만 표현하므로 짧은 시간 관찰 시 변화가 잘 인지되지 않았다.

## 해결 설계

- 전체 경과 비율(0~100%)이 증가하는 외측 원·막대
- 1분마다 새롭게 채워지는 초 단위 내측 원·막대
- 큰 남은 시간 숫자, 경과/전체 시간, 현재 백분율 병행
- 15초 시각 테스트(실제 세션/DB와 분리)
- 일시정지에서 게이지 동결, 재개 시 서버/브라우저 시간 기준 재계산

## 검증 시나리오

| ID | 작업 | 기대 결과 |
|---|---|---|
| VT01 | 15초 미리보기 시작 후 5초 경과 | 원형 두 링과 두 막대 약 1/3 채움 |
| VT02 | 미리보기 중 일시정지하고 경과 시간 변경 | 남은 시간·경과 시간·게이지 변하지 않음 |
| VT03 | 미리보기 재개 후 종료 | 통계 및 완료 회차 미반영 |
| VT04 | 실제 1분 집중 세션 중간 시점 | 전체 진행과 초 게이지, 남은 시간 동기화 |
| VT05 | 실제 세션 완료 | 기존 완료 회차·누적 분 통계에 반영 |

테스트 자료는 개발자가 실행한 검증 범위만 서술합니다. 실제 사용자 조사/평가는 별도 수행 후 기록하세요.
